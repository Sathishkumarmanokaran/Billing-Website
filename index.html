Google Drive Configuration Methods

Uses official Google Identity Services to securely store vyaparify_cloud_database.json in your personal Google Drive.

How to get a Google Client ID in 2 minutes (Click to expand)
  1. Visit Google Cloud Console.
  2. Create a free project & enable Google Drive API.
  3. Go to Credentials → Create Credentials → OAuth Client ID → Application Type: Web Application.
  4. Add your authorized JavaScript origins (e.g. http://localhost:5500, http://127.0.0.1:5500, or your web domain).
  5. Paste the generated Client ID above and click "Sign In with Google"!

Zero-Config Alternative: Paste a free 10-line Google Apps Script Web App URL from your Google account. Works on any device, phone, or local file without configuring Google Cloud Console!

Instructions for 1-minute Google Apps Script setup
  1. Click "Copy Script Code" above.
  2. Open script.google.com and click "New Project".
  3. Paste the code, click Deploy → New Deployment → Select type: Web App.
  4. Set "Execute as: Me" and "Who has access: Anyone". Click Deploy.
  5. Copy the Web App URL and paste it above!
